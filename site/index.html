Every care instruction Alexa says can be traced back to the page it came from.

CareLoop is an add-on for Alexa+ that turns a clinician's plan into tasks the patient approves, family members can help with, and a clinician can trust.

Watch the demo Read the code

Built for the Amazon Developer Hackathon 2026, Alexa+ track. A demo with synthetic data, not medical advice, and not an Amazon product.

Alexa+ remembers. CareLoop proves.

Alexa+ can remember a document, set a reminder, and reach the right person. After a hospital visit, a family needs something more: a shared record of what was agreed, who is allowed to know, what happened, and what the clinician will see.

What Alexa+ already does well

  • Remembers what you shareDocuments, emails and photos you send it.
  • Reminds the right personReminders and announcements aimed at one family member.
  • Talks naturallyUnderstands requests and replies in its own voice, with screens on an Echo Show.

What a care plan still needs, and CareLoop adds

  • Approval with the source lineNothing becomes part of the plan until the patient approves it next to the line it came from.
  • Consent that fits a familyEach person gets exactly the access the patient confirms, for as long as she chooses.
  • Privacy on a shared speakerSpeakers hear "1 new update", never a symptom or a dose.
  • Rules, not guessesOnly the clinician's own rule can raise an alert, once per episode.
  • A record the clinician can useA dated summary of what was done, missed, asked and acknowledged.

What Alexa says, and what CareLoop keeps

Alexa says as little as it needs to. The detail goes to Maya's private screen and into CareLoop's record. These exchanges come from CareLoop's end-to-end tests, run against the real server.

Heard on Maya's Echo Show

Maya

Alexa, let my brother Sam see my tasks and get updates for two weeks.

Alexa

Sam will be able to see your tasks and get update alerts, for 14 days. Is that right?

Maya

Yes.

Sam's Echo Dot: "Maya invited you to help with her care in CareLoop. Open the invitation in your Alexa app to accept."

The assistant can get permissions wrong. CareLoop reads them back and creates nothing without a yes.

Heard on Sam's Echo Dot, a shared speaker

Alexa, any CareLoop updates?

Alexa

You have 1 new CareLoop update.

Sam

Alexa

CareLoop records are unavailable.

Sam was invited to see tasks and updates, not check-ins. Values are never spoken on a shared speaker.

A model proposes the items; code checks every number against the source, and the patient decides.

What CareLoop never does

The limits are part of the product. They are what make it safe to put on a kitchen speaker.

  • Diagnose, prescribe, change a dose, or interpret a trend.
  • Invent an instruction, a number, or an alert threshold.
  • Read a symptom, a value, or a medicine aloud on a shared speaker.
  • Treat a missed check-in as "fine". The summary says it wasn't recorded.
  • Claim to monitor for emergencies. Crisis words get the emergency number, 988 in the US.
  • Share anything without the patient's confirmed consent, which she can withdraw at any time.

See it running

Without Alexa+ preview access, we built a browser simulator that behaves like Alexa+ in front of the same MCP server: two devices, account linking, local voice, and a live MCP inspector.

The three-minute demo video will appear here.

  • 30 MCP toolsPlans, documents, check-ins, family, consent, handoffs and data rights.
  • 100% recall, 0 invented numbersPrescription reading on our synthetic test set: typed PDF, scan and photo, 3 runs each.
  • 241 automated testsIncluding complete conversations against a running server.
  • Local by defaultOCR, the language model and the voice all run on the laptop, so no health text leaves it. Point the models at your own OpenAI-compatible endpoint and document text goes there instead.

For developers

CareLoop is a standard MCP server over Streamable HTTP. Any MCP client can use it, and the simulator shows how Alexa+ would. In production Alexa+ brings its own model. To run the simulator, point it at any OpenAI-compatible API, a local Ollama model, or the built-in scripted planner.

# Python 3.12+, uv, and optionally Ollama
git clone https://github.com/Ghost-141/CareLoop.git
cd CareLoop
uv sync --extra dev --extra alexa-sim --extra voice \
        --extra intake --extra ocr
cp .env.example .env   # optional: local model and voice
uv run pytest -q
scripts/run_alexa_demo.sh
  • Voice-safe results. Every tool returns one sentence safe to say aloud, plus opaque references. Private detail goes to a sandboxed MCP Apps screen.
  • MCP elicitation. Check-ins, guided reviews and consent ask their own follow-up questions mid-call.
  • Your choice of model. PaddleOCR, plus Ollama or any OpenAI-compatible endpoint, checked by deterministic code before anything is shown. Lines that read like commands to an AI are set aside.
  • Full setup, walkthrough and configuration in the README
